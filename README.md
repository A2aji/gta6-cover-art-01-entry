Sunset Press — turn your photos into a GTA 6-style poster cover, offline in the browser. Pick a layout, drop in up to 9 photos, grade them in a Vice City sunset or neon palette, letter the title in Anton with a Pacifico script subtitle, and export the cover as a PNG in the common post sizes — 1080×1080, 1080×1350, 1920×1080 and 1080×1920 — all in one click. Photos never leave your machine.

## What is in it

- 7 layouts: full-bleed hero, four-panel grid, hero-and-three, nine-panel grid, tilted snapshots, three-strip vertical, diagonal split
- 6 colour grades drawn on canvas: Sunset, Neon Nights, Vice Pink, Noir, Golden Hour, Teal Heat
- Halftone title block with gradient Anton lettering, Pacifico subtitle, tagline, star heat meter (1–5) and badge ribbon
- Per-panel crop: click a panel to select it, drag the photo to reposition it, zoom slider, pick which photo fills it, swap photos between panels
- Undo/redo for every edit, film grain + vignette toggles, drag-and-drop photo upload
- 5 built-in sample artworks (2 kit photos + 3 original procedural sunset pieces) so it works with zero uploads
- Fully offline: vendored OFL fonts (Anton, Pacifico, Bebas Neue), no network requests, no build step

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Drop photos in, pick a layout and grade, edit the caption, export.
